# Torneo Interfacultades de Fútbol 5
## Obligatorio de Bases de datos
- Integrantes: Valentina Morales y Rodrigo Montiel.

## ¿Cómo levantar la aplicación?
- Para poder levantar esta aplicación hay que tener de manera local la base de datos, el backend y el frontend. Para conseguir esto, en ese mismo orden vaya ingresando a las carpetas de este repositorio y lea los README's que allí se encuentran para levantar las partes del proyecto. Una vez terminado va a poder correr la app.

## Tecnologías utilizadas
- Python: lenguaje utilizado para el backend.
- Flask: framework utilizado para crear los endpoints y gestionar las peticiones HTTP del frontend.
- MySQL: utilizado para crear la base de datos relacional.
- mysql-connector-python: biblioteca para conectar Python con MySQL y poder ejecutar las consultas SQL.
- React: biblioteca utilizada para desarrollar la interfaz de usuario del frontend.
- JavaScript, HTML y CSS: tecnologías utilizadas para implementar la interacción, la estructura y los estilos de la interfaz del frontend.

## Tecnologías utilizadas
### Backend
- Python: lenguaje de programación usado para desarrollar la lógica del servidor.
- Flask: framework utilizado para crear la API y gestionar las solicitudes HTTP provenientes del frontend.
- MySQL: sistema gestor de bases de datos relacional utilizado para almacenar y administrar la información del torneo.
- mysql-connector-python: biblioteca usada para establecer la conexión entre Python y MySQL y ejecutar consultas SQL.
- Flask-CORS: extensión utilizada para permitir la comunicación entre el frontend y el backend, que se ejecutan en distintos orígenes.
- python-dotenv: biblioteca usada para cargar variables de configuración desde un archivo .env, como los datos de conexión a la base de datos.
- Werkzeug: biblioteca utilizada para gestionar aspectos de seguridad, como la verificación de contraseñas.

### Frontend
- React: biblioteca utilizada para desarrollar la interfaz de usuario mediante componentes reutilizables.
- JavaScript: lenguaje usado para implementar la lógica y la interacción de la interfaz.
- HTML: lenguaje utilizado para estructurar el contenido de la aplicación.
- CSS: lenguaje usado para definir los estilos y la presentación visual.
- Vite: herramienta utilizada para configurar y ejecutar el entorno de desarrollo del frontend.

## Herramientas de desarrollo
- DataGrip: herramienta utilizada para administrar la base de datos, ejecutar consultas SQL y verificar los datos.
- Git y GitHub: herramientas utilizadas para el control de versiones y el almacenamiento del código. Además facilitaba compartirlo.
